# 达人 brief、执行与效果评估

用于把方案交给具体达人，或设计发布、投流、预算与复盘。

## 单达人任务卡

| 项目 | 应写清什么 |
| --- | --- |
| 你对谁说 | 人群、生活或使用阶段、具体场景 |
| 主要回答什么 | 一个优先消费者问题 |
| 承接什么创意 | Core Idea 中的机制、共鸣、依据、体验或选择部分 |
| 主要传递的价值 | 一个主要价值及必要的支撑信息 |
| 依据是什么 | 本次 SKU 的确认口径、来源、适用条件及可用素材 |
| 共同记忆点 | 产品身份、品牌符号、统一表达或必要动作 |
| 必须展示什么 | 与任务相关的关键画面、使用过程或解释材料 |
| 创作空间 | 保留达人自己的开头、结构、个人语言与实际体验 |
| 交付要求 | 形式、条数、档期、授权范围、审核与修改安排 |
| 如何判断完成 | 与内容任务相符的表现和反馈 |

按角色选择必要信息，不把完整品牌手册塞进每条内容。专业解释者获得可核对资料，体验者获得必要产品信息和足够使用时间，比较者需要清楚的比较条件。

商业关系按适用平台与项目要求如实呈现。只有真实经历才能写作个人体验；不得安排虚构使用结果、伪装用户评价或编造评论。真实问题可归纳为答疑内容，模拟提问需注明示意。

## 内容示意结构

- **专业解释**：消费者问题→解释思路→相关依据及范围→本品如何采用→一句记忆点。
- **场景共鸣**：具体时刻→行为与矛盾→产品自然参与→相关变化或体验→共同记忆点。
- **使用体验**：自身条件→使用方法与过程→实际观察→适用限制与疑问→进一步了解路径。
- **选择比较**：选择问题→比较维度与条件→可核对信息→适合谁或怎样判断→进一步了解。

以上是可选结构，不要求所有作品同一节奏。核心画面应能解释产品的作用，单纯在剧情结尾露出包装通常不足以证明创意与产品的联系。

## 节奏与审核

按项目节点、产品实际使用周期和素材准备情况排期。先准备关键依据与承接内容，再测试表达、补齐疑问、扩大有效方向。新概念可能需要先教育，成熟概念可更快进入场景或选择内容。

倒排节点包括：信息口径确认、账号与选题、寄样及使用、提纲、脚本、拍摄、初稿、修改、发布、数据回收。用户给定的提前天数适用于该项目，不能照搬为所有品牌的固定周期。标明审核人与每个节点的实际日期。

## 预算与投流

预算应连接角色、体量、人数、条数、授权和实际报价。分别列内容生产与发布、授权、投流、必要制作与执行费用；注明含价范围。

测试前提出明确问题，例如开场是否被理解、产品是否参与故事、哪个场景引发相关疑问。在可行范围内保持受众、窗口与预算可比，再比较表达。条件不同就说明限制，不强作因果判断。

有可靠信号的内容可扩大投入；只有点赞高时，继续核查是否形成理解、品牌记忆、搜索或相关行动。需要搜索承接时，把问题词、品类词、品牌词分别对应到可用的解释、选择和产品内容。没有相关工具或数据时，给测试方案，不伪称已经完成投放。

## 按任务评估

| 内容任务 | 可选观察 | 观察重点 |
| --- | --- | --- |
| 共鸣 | 相关评论、分享、观看表现、受众反馈 | 用户是否认出自身场景，是否连接到产品 |
| 创意演绎 | 理解反馈、品牌与核心符号记忆、观看表现 | 用户记住了什么，是否理解产品参与 |
| 专业解释 | 有效提问、收藏、理解反馈、可得后续搜索 | 是否听懂依据及范围，误解是否减少 |
| 使用体验 | 方法提问、收藏、搜索、可得进店数据 | 是否理解使用方法和相关条件 |
| 选择比较 | 选择问题变化、品牌搜索、可得进店或行动数据 | 是否帮助形成判断标准 |
| 真实经验与答疑 | 已回答问题、相关追问、可得行动数据 | 是否回应真实顾虑，是否仍有信息缺口 |

这些都是可选指标，依项目目标和数据权限选择。收藏不是理解的直接证明，搜索不是成交的直接证明；需要验证理解和记忆时安排相应反馈或调查。

如计算 CPM、CPE 或进店成本，注明费用含项、曝光或互动定义、统计窗口和平台口径。同一个人可能多次接触不同内容；不能把各账号曝光简单相加为去重触达，也不能将最后一次点击独占为全部种草贡献。

## 复盘决定下一步

- **保留**：目标问题得到较好回应，品牌与产品联系清楚。
- **修改**：用户只记住故事、专业名词或达人，产品价值不清楚；定位具体断点。
- **补充**：出现反复且影响选择的新疑问，新增相应内容或角色。
- **扩大**：在可比条件及目标相关指标下有稳定信号，检查授权与投流条件后再决定。

复盘分别讨论创意表达、达人受众、内容制作、投流条件与承接体验，不将单一结果全部归因于一种因素。
