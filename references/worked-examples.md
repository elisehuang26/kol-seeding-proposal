# 推导示例：从创意到达人任务

以下品牌、访谈表达、产品设定和创意均为虚构示意，不代表实际消费者研究、已验证功效或品牌背书。真实项目用对应 SKU 的资料和当期观察替换，不照搬故事中的判断。

## 示例一：护肤产品如何分工

**原始设定**：虚构品牌“简序”推出一款面霜，希望服务晚间护肤时间零碎的人群。品牌提供了使用方法、质地资料，以及需要按实际报告解释的产品依据。

| 推导步骤 | 示例输出 | 依据与待验证项 |
| --- | --- | --- |
| 平台观察 | 计划查找晚归、带娃、睡前护理和步骤选择相关讨论 | 尚未取样，不能断言是平台趋势 |
| 洞察假设 | 想照顾自己，但复杂步骤在零碎时间里难以坚持 | 需验证是否反复出现、是否影响选择 |
| 产品回应 | 检查该面霜能否融入简洁的正常护理流程 | 以实际使用方法和资料确认，不承诺替代全部步骤 |
| 沟通主张 | 在忙碌的夜晚，让必要的护理更容易落实 | 需与产品实际用法相符 |
| 创意联想 | “晚间留白”既是日程里的空隙，也可成为护理发生的时刻 | 场景与动作连接，不承担功效证明 |
| Core Idea | “给晚间留一格”：展示不同人如何在夜晚安排中留出自己的护理一格 | 关键画面是日程格与真实使用场景交替 |

接下来分配任务：

| 达人角色 | 承接的部分 | 内容示意 |
| --- | --- | --- |
| 场景创作者 | 零碎时间中的自我照顾 | 晚归或带娃之后，实际护理时刻如何发生 |
| 垂直体验者 | 使用流程与感受 | 展示用量、质地、搭配和本人真实感受 |
| 解释者 | 产品为何适合这个使用方式 | 只解释与主张相关、可核对的资料 |
| 选择与答疑者 | 是否适合自己的日常 | 回答用法、质地偏好和搭配信息，注明个体条件 |

统一保留“晚间留一格”的画面、产品身份和核心价值，开头及个人叙事不同。若研究发现障碍主要是不会判断产品适用性，就应增加选择内容，而非继续扩大情绪故事。

## 示例二：奶粉如何分工

**原始设定**：虚构品牌“初研”针对一个尚待确认的年龄段与产品 SKU，希望帮助家长理解选购信息。当前只有任务，尚无可使用的配方、效果或具体适用依据。

| 推导步骤 | 示例输出 | 依据与待验证项 |
| --- | --- | --- |
| 平台观察 | 调研家长在读配方、比较产品和确认适用条件时提出的问题 | 收集真实问题，不能编造原话 |
| 洞察假设 | 做了很多功课，但缺少把信息转成判断的方法 | 需验证核心障碍是理解、信任还是其他原因 |
| 产品回应 | 核对 SKU、年龄阶段、标签与品牌能提供的准确解释材料 | 未确认前不提出配方优势或健康结果 |
| 沟通主张 | 帮助家长把复杂产品信息转成更清楚的选择问题 | 对应品牌可提供的信息服务，不承诺普遍适合 |
| 创意联想 | 把常见选择问题组织成一套“看得懂的选奶功课” | 让解释有统一形式 |
| Core Idea | “把选奶功课讲明白”：每条围绕一个真实选择问题，以资料与经验分工回答 | 关键机制是一张共同问题卡，接不同来源的答案 |

达人安排从问题反推：

- **问题发起者**：有相关经历的家长，呈现确实遇到的困惑，承接洞察与场景。
- **信息解释者**：核验背景及表达能力，结合准确资料解释信息含义，承接沟通主张。
- **选购整理者**：展示比较维度、适用条件与信息出处，承接选择方法。
- **真实经验分享者**：讲自己的实际经历、记录与限制，承接具体顾虑；个人经历不能替代产品普遍效果证据。

这些角色都可能由不同体量账号承担。若多数疑问属于比较环节，预算优先补充可检索的选择内容；若用户已经理解产品但难以认出适用场景，才增加相关生活内容。比例需要依据实际研究、数据、报价与目标决定。

## 检查任意案例的关键跳转

1. 观察究竟来自哪里，假设是否被写成事实？
2. 产品是否确有能力回应洞察，品牌与 SKU 是否混用？
3. 创意联想能否被理解，名字或图形是否被误当功效证据？
4. 内容角色是否对应真实的消费者问题？
5. 每个账号是否有完成任务的依据？
6. 用户最后记住了什么，反馈将改变哪一个下一步决定？
